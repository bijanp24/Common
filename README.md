# Common Styling

Shared styling source for OnlyTacos and Agronomy Studio.

## Usage

Install from GitHub:

```sh
npm install github:bijanp24/Common
```

Import the shared CSS variables:

```css
@import "@bijanp24/common/styles/theme.css";
```

The exported CSS defines `--theme-*` custom properties for surfaces, text,
brand colors, states, shadows, and focus treatment. `tokens.json` mirrors the
light-mode values for non-CSS consumers and design reference.
